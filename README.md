# IoT-Temperature-Humidity-Monitoring
IoT temperature and humidity monitoring using Wokwi and ThingSpeak.

# IoT Temperature and Humidity Monitoring

## Wokwi Simulation

Wokwi is used to simulate the IoT circuit and test the ESP32-based
temperature and humidity monitoring system.

### Wokwi Components

The simulation includes:

- ESP32 microcontroller
- DHT22 temperature and humidity sensor
- Wi-Fi connection
- Temperature and humidity data monitoring

### Wokwi Files

The `Wokwi` folder contains two main files:

- `sketch.ino` — Contains the ESP32 code used to read temperature
  and humidity data from the DHT22 sensor and send the readings
  to ThingSpeak through Wi-Fi.

- `diagram.json` — Contains the Wokwi circuit configuration, including
  the ESP32, DHT22 sensor, and their connections.

## ThingSpeak

ThingSpeak is used to receive and visualize the temperature and humidity
data generated by the Wokwi IoT simulation.

### Fields

- Field 1: Temperature
- Field 2: Humidity

### Working

The ESP32 sends the temperature and humidity readings through Wi-Fi
to the ThingSpeak channel, where the data is stored and displayed
using graphs.

### Channel

ThingSpeak Channel: https://thingspeak.mathworks.com/channels/3456825

### API Key

The API key is not included in this public repository for security.
