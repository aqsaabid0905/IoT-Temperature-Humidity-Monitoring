# ThingSpeak

ThingSpeak is used to receive and visualize the temperature and humidity
data generated by the Wokwi IoT simulation.

## Fields

- Field 1: Temperature
- Field 2: Humidity

## Working

The ESP32 sends the temperature and humidity readings through Wi-Fi
to the ThingSpeak channel, where the data is stored and displayed
using graphs.

## Channel

ThingSpeak Channel: [https://thingspeak.mathworks.com/channels/3456825/private_show]

## API Key
